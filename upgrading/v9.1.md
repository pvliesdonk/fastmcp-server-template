## v9.1 - The `code-review` skill is now `self-reviewing`

The template's local self-review skill was named `code-review`, the same name
as Claude Code's built-in `/code-review` command and the upstream
`code-review` plugin, so an agent told to "run code-review" could pick any of
the three. It is now `self-reviewing`, at `.agents/skills/self-reviewing/`.
`copier update` moves the skill, and its after-stage migration removes the
old `.claude/skills/code-review` symlink, which copier itself leaves dangling.

What the update cannot rewrite is text this project owns. Search for the old
name and change every reference to the skill, not to the plugin or to the
`claude-code-review.yml` workflow:

```bash
git grep -n 'code-review' -- ':!*claude-code-review*' ':!CHANGELOG.md'
```

Look in particular at `AGENTS.md` DOMAIN blocks, `REVIEW.md`'s
`DOMAIN-REVIEW` block, a project-owned skill that invokes the review, and
any agent memory or instruction file outside the repository that says "run
the code-review skill". A hit on `code-review:code-review` or
`code-review@claude-code-plugins` names the upstream plugin that the
automatic review workflow installs; leave it.
